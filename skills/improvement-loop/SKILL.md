# 改进回路：让"更好"可以被证明

多轮改写最容易滑进的坑是：改到第五轮，说不清哪版最好、为什么好，也退不回去。这份 skill 给一条轻量的回路：**一次一条判据，每轮和基线比，留下证据。**

它不引入多候选与独立评审——只回答一个问题：**这一版比上一版好吗？**

## 循环

```
定标准 → 立基线 → 改一处 → 量 → 归因 → 选或弃 → 记账 → 下一轮
```

| 阶段 | 产物 | 过关条件 |
|---|---|---|
| 定标准 | 一句话：什么叫更好（可判） | 能对着产出说"这条没做到" |
| 立基线 | 当前版本，原样保存 | 后面每一轮都拿它比 |
| 改一处 | 一个候选版本 | 只动一条判据或一处结构 |
| 量 | 对照表（版本 × 度量） | 差异能被数出来或被指出来 |
| 归因 | 这条改动改了哪一句、哪一节 | 答不出按"未生效"处理 |
| 选或弃 | 冠军版本 | 新版本必须严格更好，否则保留旧的 |
| 记账 | 版本文件 + 对照表 + 证据 | 随时能退回任何一版 |

## 定标准

标准写成**可判**的形式，顺序是从硬到软：

1. **可数**：行数、节数、块数、条数、张数——先能量。
2. **可指**：某类段落的有无（实现细节、测试数字、流程叙述）——能指着说。
3. **可跑**：命令能否逐字执行、输出是否来自真实运行。

写不出可判的标准，说明"更好"还没成形；先别开跑。

## 立基线与做候选

- 基线要**认真做**，不能敷衍；否则后面的"变好"可能只是变努力了。
- 候选**一次只改一条**判据。一次改五条，涨了也不知道是哪条起作用。
- 基线与候选**互相不可见**。让改候选的人看到基线，会不自觉地对照着抄或避开。

## 夹具

同一个输入要能被反复使用，否则第二轮就没法和第一轮比。

- 夹具是一份固定输入：真实仓库的副本、一段 diff、一份需求，加一句固定的任务与禁令。放进版本控制，和对照记录放在一起。
- 夹具本身要先验过：diff 能应用、仓库能构建、埋下的问题确实存在。夹具坏了，所有轮次都在测夹具。
- **夹具要让被验的东西有机会失效。** 定夹具时问一句：如果这条规则不存在，这里会出什么错？答不出来，就换一个夹具——两组都不会犯那个错时，对照没有分辨力，跑了也判不出有没有用。
- 验"别做过头"这类规则时尤其容易选错：把输入缩小到谁都不会过头，于是测不出差别。这种规则需要一个大到有诱惑的输入。
- 产物会被别人消费时（计划、规范、清单），度量不止看它本身：把它交给另一个执行者照做一次，数执行时撞上的矛盾与返工。纸面越细，越需要这一步。

## 度量与归因

先量可数的，再读不可数的：

| 类型 | 量什么 |
|---|---|
| 可数 | 行数、章节数、段落数、代码块、图片、引用数 |
| 可指 | 该有的段落有没有、该走的有没有走 |
| 可跑 | 命令能否原样复制、输出是否真实 |

**归因问句**：这条改动，改了哪一句？答得出，判据在起作用；答不出，只是碰巧写得好。

## 选优与防退化

- **冠军线**：新版本只有在标准上严格更好才替换旧版本；打平就保留旧的。这条挡住"每轮都改一点、整体却在漂"。
- **回归账本**：上一轮已经通过的行为，这一轮重跑必须仍然通过。改了 A 不许弄坏 B。
- 两版各有胜负时，先明确标准里哪条权重更高，再选；不要"感觉这版更顺"。

## 停止

三条同时满足就停：

- 连续两轮，度量不再变化；
- 新加的判据不再产生新行为；
- 剩下的差异属于判断而非规则（品味、取舍、风格）。

第三条写进说明，不要写成判据——写成判据只会让下一轮无法判定通过与否。

## 陷阱

- **只测"做出来"不测"有没有用"**：证明"这套方法能产出一份合格产物"容易，证明"它让产出变好"必须跑对照。
- **Goodhart**：优化度量而不是质量。度量只负责发现缺口，最终判断要看一份真实产出。
- **把巧合当因果**：候选变好但答不出哪处改动带来的，按未生效处理。
- **改太多**：一轮动五处，涨了也不知道为什么，坏了也不知道退哪。
- **没有版本账本**：删掉中间版本，等于删掉证据。
- **单次运行当结论**：同一夹具同一版本跑两次，结果也会不同。差距小于两次运行之间的波动，按打平处理；要下结论的差距，至少跑两次确认方向不变。
- **看过结果再写预测**：那不是预测，是合理化。动手前把预期写下来并保留原文，结果出来只做对照，不回改预测。预测错了本身就是结果的一部分。
- **拟合夹具**：每一轮都在同一个夹具上补一条规则，规则会越来越像那个夹具的答案。新规则在第二个夹具上也起作用，才算确认。
- **同一个人出题又答题**：写规则的和执行对照的是同一个模型时，对照的盲点与规则的盲点重合。条件允许时换一个执行者。

## 事实：一次真实的四版记录

同一输入、同一任务、同一禁令，只改方法（核对 2026-10-31）：

| 版本 | 方法 | 行数 | 节数 |
|---|---|---|---|
| A | 无约束 | 354 | 15 |
| B | 第一版规则 | 372 | 10 |
| C | 加一条体量判据 | 148 | 7 |
| D | 加体量判据 + 模仿高星项目 | 140 | 7 |

两条可复用的观察：

- **能执行的判据都生效了**：可复制的安装块、首屏纪律、不搬测试数字，在 B 就出现了。
- **没写下的判据完全没生效**：B 没有任何体量规则，于是 372 行；写成"≤150 行、`##` ≤8"后，C 落到 148。

只看 B 会误判成成功。**必须有基线，也必须看第二轮。**

## 输出

一份能被下一轮直接使用的记录：

1. 每一版的产出（原文件，不删）；
2. 对照表（版本 × 度量）；
3. 每条标准的证据：它改了哪一句、哪一节、哪一版；
4. 冠军是谁、为什么，以及回归账本里有哪些项必须保持通过。
