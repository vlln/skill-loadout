# 会话优先的多编组模型

本契约替代 loadout-design.md 的 v1–v3 和此前单组选用约束。技能文件不移动，真实用户配置不在开发中修改。

## 产品关系

- 技能库只展示全局本地库存，不再分全局/项目；不枚举工作区。项目技能仅在聊天框默认加载和排除，不参与编组。
- 「添加技能」使用来源下拉与输入，支持 Git 地址和本地文件/目录导入；不提供编写新技能、回收站及回收操作。磁盘旧记录不擅自删除。
- 「搜索外部技能」是独立动作，使用 Git/ClawHub/skills.sh 单一下拉和搜索框；搜索与添加来源分离。安装/导入 UI 仅提供全局目标。
- 「本机扫描位置」管理本地发现目录；「外部技能来源」管理仓库订阅。备份风险位于相关更新操作内。
- 设置/侧栏编组页不借用聊天会话，勾选表示新会话默认初始组；通过真实 awaited startup 创建事件快照，已有会话不受默认变化影响。聊天入口才显示本会话勾选，明确清空保留项目默认。
- 勾选保存不重新扫描库存、不挂载成功提示条，不卸载列表；失败保留原选择。其他视图静默刷新。
- 编组只引用全局库存；历史项目引用保留磁盘但不贡献组成员，编辑/复制须移除；新写入项目引用拒绝。不能直接引用未安装远程技能。
- 全局 Codex/Claude 支持原生环境变量，兼容 DSH_* 覆盖；Codex 内置技能为独立只读派生根，不放宽通用隐藏目录过滤。
- 编组是共享的命名成员集合；编辑定义影响使用它的会话。
- 会话可明确选择零个或多个编组；按成员并集加载，同一 {root,name} 去重。
- 同名不同来源按既有 provider 优先级选胜者，实际名单只列规范名一次；其他成员显示冲突原因。
- 取消或删除一组，只移除该组贡献；仍被其他所选组引用的技能继续可用。
- 旧 activeLoadout、enabledSkills、disabledSkills、disabledRoots、gatekeeper 不参与加载。不可读状态、技能结构错误仍阻断。
- 当前会话工作目录已发现的项目级技能默认生效（所有既有 project scope 来源），与所选编组成员取并集；全局库存仍不自动生效。
- sessionExcludedSkills[sessionId] 保存 {root,name}[]，本会话排除优先于项目默认和组成员资格；相同真实文件的别名不能绕过排除。不改变源文件或其他会话。
- 不声明禁用宿主/preset 另行提供的技能。

## 状态兼容与接口

- sessionLoadouts[sessionId] 新写入为 string[]，旧 string 读作单元素数组，空串/不存在读作 []。读取不写迁移。
- 新增统一 setSessionLoadouts(sessionId, ids)；去重、逐个验证，任一未知 id 整次拒绝，失败无部分写入。
- 旧 setSessionLoadout 和 POST loadoutId 兼容为替换整个集合（单元素或空集合）；新前端只使用 loadoutIds。
- POST /session-loadout {sessionId,loadoutIds:string[]}。同时传 loadoutId 与 loadoutIds 拒绝，非法数组元素拒绝。
- GET /session-loadout 新增 loadoutIds；effective 新增 loadouts 数组，skills 是并集实际可用规范名，members 是去重成员诊断，带 loadoutIds 标识贡献组。
- 兼容单数 loadoutId/effective.loadout 只在恰好选一组时返回该组，否则 null，绝不能把第一组当唯一实际选择。
- GET /loadouts 和 /state 新增 activeIds:string[]；旧 active 只在恰好一组时返回 id。
- effective.source 仅描述编组选择来源 session|none；无编组也可能有项目默认技能。
- effective.members 含所选组与当前项目技能并集，带 loadoutIds、projectDefault:boolean；status 为 available|missing|invalid|shadowed|excluded。项目项被排除后仍可见，可重新勾选。
- GET /session-loadout 顶层 excludedSkills 返回完整会话排除集合；POST /session-skill-exclusions {sessionId,excludedSkills:[{root,name}]} 原子替换。已有悬空/其他目录排除可保留，新项须属当前本地库存或已选组成员，失败不部分保存。
- cwd 变化按新 cwd 重算默认项目技能；不删除其他目录排除记录，切回仍遵守原选择。
- /loadout-create、/loadout-update 草稿原子保存；复制 copyFrom 可保留原组悬空引用，新成员须来自本地库存。
- 删除编组从每个会话集合中仅移除该 id；既有单数选择同样兼容。
- 旧策略字段保留不生效；显式 /loadout-import-legacy 创建普通组，不自动选用。
- /loadout-apply 兼容入口必须有明确 session，等价单组选用；旧启停 API 拒绝。
- 所有影响可用技能的变更调用 afterWrite；客户端统一变更事件与请求序号防旧响应覆盖。

## 聊天路径

- 收起：零组显示选择技能组；一组显示组名与技能数；多组显示「N 个编组 · M 个技能」。
- 展开多选列表，每组有独立勾选状态，可连续选多组，不每次关闭菜单；提交中防重复，成功才更新，失败保留选择。
- 清空编组只清空组选择，项目默认技能仍可用，文案不得暗示清空全部技能。
- 聊天主菜单只负责编组多选与必要取消；项目技能收进独立二级菜单，使用 /session-skill-exclusions 做会话排除/恢复。
- 「显示已生效 Skills」二级菜单承载实际技能名单与诊断，技能可打开只读预览，不在主菜单平铺。
- 主菜单不提供新建、技能库管理、编组管理、手动刷新、逐组编辑及常驻历史说明；管理职责留在设置。
- 零组但有项目技能时收起显示项目技能数量，不显示仿佛没有可用技能的状态；实际技能名单是并集去重结果。
- 编组创建、编辑留在设置；不在聊天菜单附加每组编辑项。
- 打开菜单、变更事件时静默刷新；切会话隔离迟到响应，预览同样受会话及请求序号保护。
- 不声称切组删除既有聊天历史。

## 管理与库存路径

- 一级：编组 / 技能库。技能库只展示全局本地库存，不含项目或第二层本地/安装切换。
- 项目技能仅在聊天管理；技能库保留搜索、详情、本机扫描位置与外部来源管理，不提供回收及编写技能入口。
- 去掉重复标题、整排孤立统计；搜索与维护按钮同一紧凑工具栏。使用宿主间距/控件 token，窄屏换行而不横向溢出。
- 外部搜索与添加分开，安装/导入仅写全局目标；成功后库存刷新并允许返回查看。
- 编组编辑候选来自全局库存，标明来源；搜索名称/简介、批量勾选、已选优先，异常可见。
- 点击编组名称在原列表行下展开成员编辑；新建、另存同样行内展开，不弹独立编辑对话框。编辑是草稿，保存一次提交，取消无写入，失败保留草稿与可见错误。
- 组行左侧是名称/展开与数量，右侧是默认勾选与固定更多操作；不再重复编辑按钮。设置默认选择和共享定义分离。
- 管理内编辑结束收起回列表；删除确认仍用宿主确认框。旧直接编辑入口仅作兼容，不在聊天主菜单暴露。
- 共享编辑提示影响范围，删除提示其他所选组保留。

## 会话上下文

- 不注册额外 loadout runtime-context，不向模型重复描述编组、默认选择、排除规则及技能名单；保持 DSH 原生上下文机制。
- 技能选择/成员/排除等变更使 provider 缓存失效，由宿主原生 skill catalog 表达最终可用集合；实际技能读取使用同一会话解析逻辑。
- catalog 的内容更新、去重、压缩/溢出后的重建由宿主原生技能插件负责；不修改宿主投影或历史。
- 不自动恢复冷会话，不通过注入配置说明绕过目录限制。

## 验收

- 旧单选 string 读取不丢，下一次写入是数组；空选择始终为空。
- A 选 L1+L2，B 选 L3：彼此独立，修改 A 不影响 B 选择。
- L1={alpha,beta},L2={beta,gamma}：并集三项；移除 L1 后 beta/gamma 保留。
- 同名不同来源按 provider 一致性去重；API/聊天/宿主实际目录一致。
- 多选时编辑组、删除组、创建并追加都不误清空其他组。
- 未安装结果不能进组；安装只进库存；全局与项目库存可区分。
- 创建、编辑、另存、取消、失败恢复、安装回流、窄屏实际浏览器通过。
- 类型检查、构建、产物一致性、完整测试通过；独立实例验证不动真实配置。
