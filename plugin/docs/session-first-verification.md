## 真实宿主验证

独立 HOME、DSH_HOME 与随机端口；只使用三个合成技能，没有配置模型凭据或修改真实会话。

| 操作 | 实测结果 |
|---|---|
| A 选 alpha，B 选 beta | 宿主 `skills/list` 分别只返回各自技能 |
| 热缓存后把 A 的组成员改为 gamma | A 立即返回 gamma，B 仍 beta |
| 删除 A 所用的组 | A 返回空，B 不变 |
| B 选择不使用编组 | B 返回空 |
| 缺变更标记头写请求 | 403，未变更选择 |
| 选组后的 `/` 菜单 | 显示实际允许的技能名与简介 |

真实 SkillRegistry 与工具调用回归另覆盖：原生/外部/项目来源、同名优先级、组选择清除后的阻断、缓存候选重新校验。

## 浏览器路径

- 聊天入口新建 → 全部库存批量选两项 → 创建并用于会话 → 返回聊天，数量与名单一致。
- 编辑当前组 → 取消：无写入；编辑 → 保存：直接返回聊天并更新数量。
- 管理页另存新组：原组和当前会话选择不变。
- 技能库搜索与详情：保留库存操作，无全局启用开关，内建详情只出现一个对话框。
- 深色桌面与 390×844 窄屏：编辑器在视口内，主操作可见。
- 浏览器过程中没有 pageerror。
- 独立审查发现聊天入口的子对话框隐藏共享错误提示；修复后在浏览器拦截删除请求返回 500，确认错误出现在仍打开的唯一对话框内，未执行真实删除。

验证中修复了两条 mock 测试遗漏：叠加 portal 对话框拦截点击；provider 注册 id 与候选 id 不一致导致宿主技能目录拒绝读取。对应回归已补。

## 证据范围与限制

- 已验证宿主目录、实际工具调用和浏览器操作；未调用收费模型，未证明模型行为质量。
- 编组控制本插件管理的库存；不声明禁用宿主或 preset 另外提供的技能。
- 已进入聊天历史的内容不会因切组被删除。
- 多人同时保存同一共享组为后写覆盖，尚无版本冲突提示。
- 编辑器可选库存按当前会话项目范围提供；其他工作区可在技能库浏览。
- 真实用户配置迁移没有执行；旧策略保存不改、导入显式确认由隔离夹具验证。
- 二级第三方仓库目录所有弹窗组合尚未逐一浏览器验收。
