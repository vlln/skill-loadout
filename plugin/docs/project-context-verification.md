## 行为

- 当前工作目录的 project scope 技能默认可用，与多编组成员取并集；全局库存仍按组加载。
- 聊天列表单独显示项目技能，取消勾选写会话排除，优先于组成员；重新勾选可解除同文件别名排除。
- 排除记录按项目 root/name 保留，切工作目录不把别的项目排除丢掉；当前目录取 workingDirectory 服务的已提交值。
- 本地库存平铺全局/项目分区；本地/安装使用轻量二级入口，无第三层切换。当前项目即使未登记为工作区也优先展示。

## 真实宿主与浏览器

- 在独立项目创建会话，不选任何组：宿主 skills/list 返回 project-check。
- 排除 project-check 后宿主目录为空；恢复后重新可用；API 项目诊断与调用目录一致。
- 浏览器项目项可勾选/取消，caption 从项目技能1变0再回1；取消后项目项仍可见。
- 库存能搜索当前未登记项目技能；其他登记工作区不会静默替代当前项目。
- 页面去除孤立统计条、回收站行和第三层 segmented tabs，维护操作集中工具栏。

## 时序与限制

- 变更后同步标脏缓存，下一次模型请求前等待刷新，宿主投影按当前快照注入。不会中断或追溯修改已发出的请求。
- 运行时上下文是合并快照，其他贡献变化可能使整个快照重新发布；不承诺独立通知字符串在所有历史中严格只出现一次。
- 不主动唤醒、恢复冷会话；已有冷会话 `/` 目录限制仍见 multi-group-verification.md。
- 未用真实模型对话验证语义遵从度，也未安装进用户真实 profile。
