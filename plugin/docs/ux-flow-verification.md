# 编组与技能库操作结构验证

2026-11-03，隔离 HOME/DSH_HOME，真实宿主 Web + Chrome headless 验证；未修改用户真实配置。

## 改动契约

- 主导航仅编组/技能库；技能库直接展示全局/项目库存。
- 添加技能先选择来源或本地导入/编写，再进入流程；添加子页只提供返回技能库与当前流程操作，无重复本地/安装页签和来源页签。
- 管理来源为独立入口；子对话框取代管理弹窗，避免多个 focus trap。
- 编组列表为紧凑行：名称/数量、会话勾选、编辑、复制/删除菜单。无活动会话不显示会话勾选。
- 取消全部编组仅在有选择时进入页面更多菜单，不影响项目默认技能。
- 空 Git 库没有无效搜索/筛选/刷新，提供可见的添加 Git 仓库主按钮。
- 安装位置在安装确认时选择；备份与刷新说明放在来源管理及相关操作对话框。
- 创建统一收在添加技能流程；帮助菜单收纳 GitHub/问题反馈。
